Local resume project

Job Fill

Upload a resume to an OpenAI vector store once. On an application, focus a long answer box and draft. The draft searches that store. You review the text before it is inserted. The form is never submitted for you.

Preview only. In Chrome, open extensions, turn on Developer mode, choose Load unpacked, and select this project folder.

      How the answer should sound

      OpenAI

      A draft sends your API key's vector store id, the question, a short excerpt of the job page, and any notes. Resume files stay in the store.

      Create a key at platform.openai.com/api-keys. PDF reading uses a local library: run npm install in this folder, then reload the extension. Word and text files work without that.

      On the application

      1. Click the long answer field.
      2. Choose Draft from resume, or press Alt + Shift + J.
      3. Read the draft. Insert it only if it sticks to your real experience.

      Drafts are instructed not to invent employers, degrees, tools, or numbers. You still need to read them.
